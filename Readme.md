## Файлы
- `index.html` — готовый сайт. Один самодостаточный файл: стили, скрипты и фотографии (base64) внутри. Открывается двойным щелчком, грузится на любой хостинг как есть.
- `site/template_min.html` — актуальный минималистичный шаблон (плейсхолдеры `{{HERO_CARD}}`, `{{ABOUT}}`, `{{SITE_URL}}`).
- `site/template_v1.html` — архив первой, «плакатной» версии сайта.
- ~~`site/template.html`~~ — прежний шаблон с плейсхолдерами `{{HERO_BG}}`, `{{HERO_CARD}}`, `{{ABOUT}}`, `{{POSTER}}`, `{{G1}}…{{G4}}`, `{{AVATAR}}`. Текст и вёрстку правим здесь.
- `site/assets/` — обработанные фото под чёрно-жёлтую гамму:
  - `hero_card.jpg` — он за работой (главный кадр в hero)
  - `hero_bg.jpg` — размытый фон hero (из того же кадра)
  - `about.jpg` — он и клиент (блок «О себе»)
  - `event_poster.jpg` — афиша мастер-класса в Чебоксарах (блок «Мастер-классы»)
  - `g1…g4.jpg` — галерея «Работы и процесс»
  - `avatar.jpg` — аватар из Telegram
  - `tg/` — исходники, скачанные из канала
- `grade.py` — скрипт цветокоррекции (duotone чёрный → янтарный → жёлтый, виньетка, зерно). Правите `STOPS`, если нужен другой оттенок.
- `build.py` — сборка: сжимает фото, вшивает их в HTML, перезаписывает `index.html`.
  Запуск: `python3 build.py` (нужен `pip install pillow`).

## Публикация и продвижение
- `PROMOTION.md` — пошаговый план продвижения: SEO, шапки профилей, готовые тексты постов, локальный поиск, контент-план, рассылка барбершопам, UTM-метки.
- `promo/post_1080x1350.jpg` — креатив для поста (Telegram / Instagram).
- `promo/story_1080x1350` → `promo/story_1080x1920.jpg` — креатив для сторис.
- `og.jpg` — превью ссылки для соцсетей (1200×630).
- `public/` — папка для загрузки на хостинг (index.html + og.jpg).
- `deploy/` — **боевая сборка** под домен barber-fedor.ru (index.html, og.jpg, favicon.ico, robots.txt, sitemap.xml, _redirects).
- `barber-fedor.ru.zip` — этот же пакет архивом для Netlify Drop.
- `LAUNCH.md` — пошаговый запуск: публикация, DNS, привязка домена, Метрика, Вебмастер.
- Живой предпросмотр запускается командой:
  `cd public && python3 -m http.server 8080 --bind 0.0.0.0`

### Сборка с доменом
```bash
SITE_URL=https://barber-fedor.ru OUT_DIR=deploy python3 build.py
```
Тогда в HTML подставятся абсолютные ссылки для Open Graph, а также создадутся `sitemap.xml`, `robots.txt` и папка `deploy/` для загрузки на хостинг.

## Публикация
- **Netlify / Vercel** — перетащить папку с `index.html`.
- **GitHub Pages** — положить `index.html` в репозиторий, включить Pages.
- Свой домен — в настройках хостинга.

## Технически
- Проверено: 390 / 820 / 1024 / 1440 / 1920 px, консольных ошибок нет.
- Hero целиком влезает в первый экран на 1440×900 и других десктопных высотах.
- Доступность: `aria-*` в меню и FAQ, фокус-стили, поддержка `prefers-reduced-motion`.
- Без внешних шрифтов и библиотек — работает офлайн, грузится мгновенно.
